# App repository template

Copy this directory into a separate Git repository, choose your own reverse-domain app ID, update the manifest/text, and develop the frontend. `neon-app/` is the installable package. Source, build tooling, tests, license and documentation may live outside it. Do not put secrets or local settings in either the package or Git repository.

See ../../docs/APP_CENTER.md for the catalog entry, immutable Git commit, supported API, installation scope and administrator workflow. This is a development template, not a published or automatically installed application. `org.neon.*` IDs are reserved for the desktop core.
